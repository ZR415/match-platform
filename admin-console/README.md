# 平台管理端演示 · admin-console

PC 端运营管理后台，单文件应用（`admin.html`），1280 宽屏布局，hash 路由。

## 运行

```bash
# 仓库根目录
python -m http.server 5173
# 浏览器打开
http://localhost:5173/admin-console/admin.html
```

登录页已预填演示账号：`admin` / `admin123`，点击「登录」进入。

## 目录

单文件结构，`admin.html` 内依次为：

1. Mock 数据（30 条用户、帖子、举报、申诉、待审内容、通知）
2. 通用组件（Icon / Card / Btn / Badge / Modal / Toast）
3. 登录页
4. 主框架（深色侧边栏 + 面包屑 + 通知铃铛 + 管理员头像菜单）
5. 数据看板
6. 审核中心
7. 用户管理
8. 帖子管理
9. App 入口（`authed` 状态 + `hashchange` 监听）

## 路由

| 路由 | 页面 | 说明 |
| --- | --- | --- |
| `#/login` | 登录 | 未登录时兜底 |
| `#/dashboard` | 数据看板 | 指标卡、趋势、待办 |
| `#/audit` | 审核中心 | 三个 Tab：投诉举报 / 评价申诉 / 内容审核 |
| `#/users` | 用户管理 | 用户表格、封禁 / 解封 |
| `#/posts` | 帖子管理 | 帖子检索、下架 |

## 审核中心交互闭环

| 操作 | 弹窗内容 | 提交结果 |
| --- | --- | --- |
| 忽略举报 | 忽略理由单选（证据不足 / 恶意举报 / 未发现违规 / 双方存在误会 / 其他） | 移出待处理队列 + Toast |
| 封禁并删帖 | 违规类型、封禁时长（3/7/30 天/永久）、上报安全中心勾选、处理备注 | 用户进入封禁态、帖子下架、举报移出或标记「已上报」 |
| 驳回申诉 | 原因单选（证据不足 / 申诉理由不成立 / 态度问题 / 其他原因）+ 补充说明 | 申诉标记「已处理」，原评价保留 |
| 撤销差评 | 原因单选（举证充分 / 存在恶意评价 / 沟通误会 / 其他原因）+ 补充说明 | 申诉「已处理」，评价星级归零 |
| 下架内容 | 违规类型单选（广告引流 / 色情低俗 / 违法违规 / 其他）+ 补充说明 | 移出待审队列（视为已下架） |
| 通过内容 | 审核备注输入 | 移出待审队列并提示已发布 |

## 用户管理

- 30 条 Mock 用户，支持姓名 / 学校 / 专业 / ID 搜索；
- 状态三态：正常（绿）、封禁中（剩 X 天，黄）、永久封禁（红）；
- 正常用户操作列为「封禁」，点击弹出：封禁原因单选（7 项）+ 补充说明 + 时长（3/7/30 天/永久）；
- 封禁后按钮变为「解除封禁」，点击弹出：解封理由（申诉通过 / 期满释放 / 误判纠正 / 其他）+ 补充说明；
- 确认解封后状态恢复「正常」，按钮恢复「封禁」。

## 全局交互

- 通知铃铛：下拉面板、未读红点、全部已读；
- 管理员头像：个人信息 / 修改密码 / 退出登录；
- 退出登录：清空登录态并替换路由到登录页。

## Vercel 部署

本项目是纯静态页面，无需构建：

| 配置项 | 值 |
| --- | --- |
| Root Directory | `admin-console` |
| Framework Preset | `Other` |
| Build Command | 留空 |
| Output Directory | 留空 |
| Install Command | 留空 |

入口文件是 `admin.html`，因此根路径 `/` 需要通过 `vercel.json` 重写（仓库已内置）：

```json
{ "rewrites": [{ "source": "/", "destination": "/admin.html" }] }
```

部署后访问 `/` 或 `/admin.html` 都可以打开后台。
