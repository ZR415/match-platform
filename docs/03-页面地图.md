# 页面地图

> 本页只描述 Demo 已实现的路由与页面栈，不代表产品需求范围；新增页面与分期以 [Issue #27](https://github.com/ZR415/match-platform/issues/27) 为准。

## 一、用户端（user-app）

页面栈由 `src/07-app.js` 管理，`renderScreen(route)` 按名称分发。

| 页面 key | 页面 | 入口 | 说明 |
| --- | --- | --- | --- |
| `privacy` | 隐私政策引导 | 首次进入 | 主页面的栈底 |
| `register` | 登录 / 注册 | 同意并继续 | Tab 双轨 |
| `auth` | 实名认证 | 注册提交 | 姓名 / 学校 / 专业 / 学号 |
| `setup` | 完善资料 | 认证通过 | Step1~3 |
| `square` | 广场 | 底部 Tab / 登录 | 主页面 |
| `search` | 搜索 | 广场搜索入口 | 帖子 / 用户双 Tab |
| `post` | 发帖 | 底部 + 号 | 二级页面 |
| `detail` | 帖子详情 | 点击帖子卡片 | 支持 `?page=detail&postId=` |
| `match` | 精准匹配 | 底部 Tab | 入口 / 来源 / 筛选 / Loading / 结果 / 空态 |
| `ai` | AI 对话 | 发帖 / 广场 | AI 写作 |
| `messages` | 消息列表 | 底部 Tab | 会话列表 |
| `chat` | 聊天 | 消息 / 详情 | 支持 `?page=chat&chatId=` |
| `profile` | 我的 | 底部 Tab | 个人主页 |
| `library` | 个人信息库 | 我的 | 编辑与预览 |
| `assets` | 资产列表 | 我的 | 收藏 / 发布 / 评价 |
| `favorites` | 收藏 | 我的 | 收藏帖子 |
| `otherProfile` | 他人主页 | 匹配结果 / 详情 | 支持 `?page=otherProfile&userId=` |
| `help` | 帮助与反馈 | 设置 | 常见问题 |
| `settings` | 设置 | 我的 | 隐私 / 通知 / 退出登录 |

### 页面栈规则

| 方法 | 行为 | 使用场景 |
| --- | --- | --- |
| `go(name, params)` | 入栈 | 卡片、按钮、快捷指令跳转 |
| `back()` | 出栈，栈底兜底回 `square` | Header 返回 |
| `tab(name)` | 重置为单层栈 | 底部 Tab 切换、退出登录 |
| `onTab('post')` | 走 `go('post')` | 底部 + 号 |

## 二、管理端（admin-console）

Hash 路由，`getPath()` 读取 `location.hash`，`App` 监听 `hashchange`。

| 路由 | 页面 | 主要内容 |
| --- | --- | --- |
| `#/login` | 登录 | 账号密码，预填演示账号 |
| `#/dashboard` | 数据看板 | 指标卡、趋势、待办 |
| `#/audit` | 审核中心 | Tab：投诉举报 / 评价申诉 / 内容审核 |
| `#/users` | 用户管理 | 30 条用户、封禁 / 解封 |
| `#/posts` | 帖子管理 | 帖子检索、下架 / 恢复 |

### 布局结构

```
┌──────────────────────────────────────────────┐
│ 深色侧边栏 │ 面包屑栏（系统名 › 当前页）        │
│ 品牌区     │ 主内容区                          │
│ 平台管理   │ ┌───────────────────────────────┐ │
│ 数据看板   │ │ 页面标题 + 操作区              │ │
│ 审核中心   │ ├───────────────────────────────┤ │
│ 用户管理   │ │ 白卡：表格 / 左右分栏详情      │ │
│ 帖子管理   │ └───────────────────────────────┘ │
└──────────────────────────────────────────────┘
```

审核中心右侧详情区根据 Tab 渲染：

| Tab | 详情组件 | 底部操作 |
| --- | --- | --- |
| 投诉举报 | `ReportDetail` | 忽略举报 / 封禁并删帖 |
| 评价申诉 | `AppealDetail` | 驳回 / 撤销差评 |
| 内容审核 | `ContentDetail` | 下架 / 通过 |
