## v1.2.0 · 2026-11-01

### 管理端 · 审核与用户管理业务流完善

- 评价申诉：驳回 / 撤销差评补齐居中弹窗，含原因单选与补充说明，提交后 Toast 并更新状态；
- 内容审核：下架弹窗新增违规类型单选（广告引流 / 色情低俗 / 违法违规 / 其他），通过弹窗新增审核备注；
- 用户管理：
  - Mock 用户扩充至 30 条，页头实时统计各状态人数；
  - 状态列三态展示：正常 / 封禁中（剩 X 天）/ 永久封禁，带彩色圆点；
  - 封禁弹窗：7 项原因单选 + 补充说明 + 时长（3/7/30 天/永久）；
  - 解除封禁弹窗：4 项解封理由 + 补充说明；
  - 封禁与解封按钮随状态自动切换。
